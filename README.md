## 🚀 Projects

### 🌱 IoT Smart Planter
An IoT-based smart planter that automatically monitors and maintains optimal conditions for plant growth.

**✨ Features:**
- 🌡️ Temperature and humidity monitoring
- 💧 Automatic soil moisture detection and irrigation
- 📱 Real-time sensor monitoring
- 📊 Live data display
- 🌐 IoT-enabled remote monitoring

**🛠️ Technologies Used:**
- Arduino UNO / ESP32
- Soil Moisture Sensor
- DHT11/DHT22 Sensor
- Water Pump & Relay Module
- Embedded C / Arduino IDE
- IoT Platform (Blynk/ThingSpeak/Firebase)
